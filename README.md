# Gold Mine 3D

Mobile-first 3D gold mining game built with Three.js.

## Features
- Dig dirt / gravel
- Drivable excavator, payloader, dump truck
- Working sluice that washes gravel into gold
- Earn money by selling gold
- Upgrade shop (dig power, truck capacity, machine speed)
- Touch joystick + look controls for phones
- Real collisions (can't walk through dirt)

## How to Play
1. Open `index.html` in a browser (or host it)
2. Left side = move joystick
3. Right side = look around
4. Walk to machines → **ENTER**
5. **DIG** with excavator or on foot
6. **SCOOP** gravel with payloader (loads truck when close)
7. Drive dump truck to sluice → **DUMP**
8. Pick up gold → open **SHOP** → sell gold for money → buy upgrades

## Controls (Phone)
- Joystick (left) – move / drive
- Drag right half – look
- DIG / SCOOP / DUMP button
- ENTER / EXIT vehicle
- SHOP – upgrades & sell gold

## Run Locally
Just open `index.html`. No build step required.
